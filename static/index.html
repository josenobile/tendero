La tesis

El catálogo de herramientas WebMCP por defecto —buscar, agregar al carrito, pagar— no es neutral: exporta supuestos gringos, así que esta tienda registra las nueve herramientas que una venta colombiana sí exige y deja el clic que la cierra en manos de una persona.

The default WebMCP tool set — search, add to cart, check out — is not neutral: it exports US assumptions, so this store registers the nine tools a Colombian sale actually requires and leaves the click that closes it to a human.

Lo único que no ocurre es el registro de las herramientas para un agente. Abrila en un navegador con WebMCP (ChatGPT Atlas, o Chrome con el flag de WebMCP) para ver la superficie dinámica.
